# 001 Project Overview

Проект про долгосрочные инвестиции в украинские ОВДП.

## Что мы строим

Цель проекта - вырастить понятный, документированный рабочий процесс для:

- сбора и нормализации данных по ОВДП;
- анализа доходности, сроков, валюты и рисков;
- формирования правил принятия решений;
- ведения подробного журнала планов и принятых решений.

## Основной источник данных

- `https://next.privat24.ua/bonds/list`

## Как работаем

1. Сначала фиксируем наблюдения и допущения.
2. Потом описываем логику рынка и доступные данные.
3. Затем превращаем это в правила, скиллы и маршруты решения задач.
4. Любое важное решение документируем отдельно, чтобы к нему можно было вернуться.

## Текущий статус

Пока у нас есть:

- понимание одного основного источника данных;
- общее представление о логике рынка ОВДП;
- намерение развивать идеи и правила по ходу работы.

## Следующий шаг

Собрать стартовый документ с:

- целями проекта;
- списком рабочих допущений;
- открытыми вопросами;
- первым деревом документации и решений.
