# 003 Vision

## Цель

Сделать проект, который помогает принимать долгосрочные инвестиционные решения по украинским ОВДП на основе прозрачных данных и зафиксированных правил.

## Принципы

- Данные важнее интуиции, но интуиция помогает формулировать гипотезы.
- Любое важное решение должно быть объяснимым.
- Источники, допущения и ограничения должны быть записаны.
- Правила должны быть простыми для проверки и пересмотра.

## Первичные вопросы

- Какие поля реально доступны в источнике `Privat24`?
- Что именно мы считаем хорошей облигацией для долгосрочного инвестора?
- Какие ограничения важнее всего: ликвидность, валюта, срок, налоговая нагрузка, возможность реинвестирования?
- Какой формат результата нужен: заметки, таблица, аналитический отчёт или автоматизированный помощник?
