# 005 Data Sources

## Primary source

- `Privat24 bonds list`: `https://next.privat24.ua/bonds/list`

## What we need to capture

- Название выпуска.
- Валюта.
- Доходность.
- Дата погашения.
- Цена или условия покупки.
- Ограничения по доступности, если они есть.

## Source notes

- Важно отдельно фиксировать, какие поля мы видим напрямую, а какие выводим косвенно.
- Если структура источника изменится, это должно попасть в журнал решений.
