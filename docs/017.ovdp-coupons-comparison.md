# 017 OVDP Coupons Comparison

## Source

- API route: `POST https://next.privat24.ua/api/p24/pub/bonds`
- Request action: `bargaining`
- Runtime bootstrap: `GET https://next.privat24.ua/api/p24/init` for public `xref`
- Quotation date in API response: `29.07.2026`

## Access Flow

- Browser cookies from `next_privat24_ua_cookies.json` were enough to call `GET /api/p24/init`.
- `GET /api/p24/init` returned public session metadata with `session_type: public`, `base_url: api/p24/pub/`, and `xref`.
- `POST /api/p24/pub/bonds` with body `{ "action": "bargaining", "xref": "<init xref>" }` returned `status: success`.
- `POST /api/p24/bonds` with the same body returned `session_was_expired`, so the working route for public market data is `/api/p24/pub/bonds`.
- A no-cookie `GET /api/p24/init` returned `error_code: 51`, `session was expired`; current minimum still requires browser cookies or another bootstrap cookie source.

## Notes

- Таблица ниже использует `sellPrice` и `sellYield`, потому что это сторона покупки для клиента в UI Приват24.
- Купоны отсортированы по дате выплаты по возрастанию; исходный API возвращает их не всегда в календарном порядке.
- `Gross Result` = сумма будущих купонов + погашение - `sellPrice` на 1 облигацию, без учета налогов, реинвестирования, валютного риска и изменения цены до погашения.
- Сравнивать бумаги корректнее внутри одной валюты.
