# 014 Auth Bridge Minimum Flow

## Goal

Зафиксировать минимальный успешный кейс запроса/передачи auth bridge для `https://www.privat24.ua/http` и описать, какие артефакты состояния он создаёт.

## What We Found

- `X-Request-origin: https://next.privat24.ua` является обязательным и должен совпадать точно;
- `Origin` сам по себе не даёт нужного результата;
- `GET /http` с правильным `X-Request-origin` возвращает `status: success` и `step.id = show_login_phone_form`;
- `GET /http?phone=380501234567` с правильным `X-Request-origin` создаёт cookie `defaultPageToken_*` и открывает queued state;
- следующий `GET /http` с тем же cookie возвращает `show_ivr_form` и payload с `phone`, `ivrPhone`, `alternate_cmd`, `alternate_cmd_timer`;
- queued state одноразовый: после одного follow-up `GET` сервер снова отвечает пустым `success`;
- `phone=test` даёт `unsupported_registration_for_foreign_client`, значит `phone` валидируется на сервере.

## Minimal Successful Path

1. Отправить `GET https://www.privat24.ua/http` с header:
   - `X-Request-origin: https://next.privat24.ua`
2. Либо сразу отправить:
   - `GET https://www.privat24.ua/http?phone=380501234567`
   - тот же header `X-Request-origin: https://next.privat24.ua`
3. Сохранить cookie jar с `defaultPageToken_*`.
4. Сразу сделать следующий `GET https://www.privat24.ua/http` с тем же cookie jar.
5. Зафиксировать queued response:
   - `cmd: show_ivr_form`
   - `alternate_cmd: show_sms_form`
   - `alternate_cmd_timer: 30`
   - `phone: +380501234567`
   - `ivrPhone: +380567976010`
6. Сразу повторить `GET /http` и убедиться, что state уже consumed.

## Validation Boundaries

- `X-Request-origin: https://next.privat24.ua` работает;
- `X-Request-origin: next.privat24.ua` не работает;
- `X-Request-origin: https://evil.example` не работает;
- `phone`, `login`, `card_id`, `sms_incoming_password`, `ivr_3digits` принимаются как параметры, но только `phone` показал reusable queued state;
- `login`, `card_id`, `sms_incoming_password`, `ivr_3digits` в наблюдаемом flow не продвинули bridge в новый устойчивый state.

## Current Interpretation

- `defaultPageToken_*` выглядит как минимальный bridge artifact;
- это не полноценная durable session, а одноразовый state carrier;
- `sid` и `dyn_string` всё ещё не найдены;
- `redirect` по-прежнему требует `sid` и не принимает наши текущие кандидаты.
