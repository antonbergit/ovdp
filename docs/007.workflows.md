# 007 Workflows

## 1. Разбор нового выпуска

1. Снять доступные поля из источника.
2. Проверить срок, доходность и валюту.
3. Сопоставить выпуск с текущими правилами.
4. Зафиксировать вывод и причину.

## 2. Обновление правил

1. Получить новое наблюдение или кейс.
2. Проверить, ломает ли оно текущие допущения.
3. Обновить правила.
4. Записать решение в `docs/008.decisions.md`.

## 3. Исследование источника данных

1. Проверить доступные поля и структуру страницы.
2. Отметить ограничения источника.
3. Решить, достаточно ли ручного анализа или нужна автоматизация.
