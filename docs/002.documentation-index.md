# 002 Documentation Index

Эта папка хранит рабочую память проекта.

Рекомендуемая структура:

- `001.handoff-checklist.md` - стартовый handoff-аудит и короткий чеклист восстановления контекста;
- `003.vision.md` - цель проекта и границы;
- `004.assumptions.md` - исходные допущения и гипотезы;
- `005.data-sources.md` - источники данных и их ограничения;
- `006.rules.md` - правила для агента и рабочие соглашения;
- `007.workflows.md` - маршруты решения типовых задач;
- `008.decisions.md` - журнал принятых решений;
- `009.storage-and-history.md` - подход к полному сбору данных и хранению истории;
- `010.bonds-data-structure.md` - результаты эксперимента по извлечению bonds-данных и наблюдаемая структура;
- `011.session-bootstrap-experiments.md` - набор экспериментов по поиску минимальной сессии и transferable cookies;
- `012.operator-cheatsheet.md` - короткая операционная шпаргалка для быстрого восстановления контекста;
- `013.experimental-runbook.md` - короткий рабочий маршрут для следующего цикла экспериментов;
- `014.auth-bridge-minimum-flow.md` - минимальный успешный auth-bridge кейс и правила одноразового state handoff;
- `015.cookie-candidate-analysis.md` - разбор браузерного cookie-дампа и список кандидатов на обязательные auth cookies.
- `016.ovdp-comparison-table.md` - сравнительная таблица ОВДП, извлеченная из снапшота страницы.

## Naming Rule

Все markdown-артефакты в проекте именуем по маске `NNN.artefact_name.md`, где:

- `NNN` - строко-числовой префикс-индекс, начинающийся с `001`;
- `artefact_name` - краткое понятное имя на латинице в lowercase;
- порядковый номер фиксирует последовательность чтения и восстановления контекста при handoff.
