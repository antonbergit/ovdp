# 010 Bonds Data Structure

## Goal

Проверить, какие данные по облигациям реально доступны в `Privat24`, и зафиксировать наблюдаемую структуру для дальнейшего хранения в базе.

## Experiment Summary

Что удалось выяснить:

- страница `https://next.privat24.ua/bonds/list` - это SPA, а не прямой JSON-эндпоинт;
- фронт использует базовый API-путь `/api/p24/`;
- bonds-ресурс расположен как `/api/p24/bonds`;
- публичные запросы к `bonds` без сессии возвращают `session_was_expired` с `error_code: 95`;
- сессионный bootstrap идёт через `API_INITIAL` и использует `dyn_string` плюс заголовок `X-Requested-With-Alias`.

## Live Probe Result

Проверка следующих действий:

- `init`
- `list`
- `rates`
- `briefcase`
- `publicDocuments`
- `schedule`

Все они на прямом вызове без сессии вернули один и тот же результат:

- HTTP `400`
- `status: error`
- `error_code: 95`
- `message: session_was_expired`

Вывод:

- сырой список облигаций сейчас нельзя получить без корректной session/XREF цепочки;
- но структура модели и контракт API уже видны в JS-бандле.

## Observed API Contract

Из бандла фронта:

- `API_BASE = /api/p24/`
- `API_BONDS = bonds`
- модель bonds имеет `idAttribute = isin`
- для публичного списка используются фильтры по типу:
  - `all`
  - `ordinary`
  - `military`
- для валюты используются значения:
  - `all`
  - `uah`
  - `usd`
  - `eur`

## Observed Bond Fields

У модели облигации в бандле подтверждены следующие поля:

- `isin`
- `maturity`
- `sellYield`
- `sellPrice`
- `quotationDate`
- `coupons`
- `currency`

Дополнительно в связанных структурах видны:

- `coupon.value`
- `coupon.paymentDate`

## Related Briefcase Fields

В связанных данных по портфелю/briefcase видны поля баланса:

- `name`
- `isin`
- `currency`
- `type`
- `amount`
- `maturity`
- `termMaturity`
- `military`
- `totalPrice`

И связанные вложенные сущности:

- `saleDeal.amount`
- `saleDeal.yield`
- `saleDeal.date`
- `buyDetails.price`
- `buyDetails.yield`
- `account.number`
- `account.state`
- `account.openingDate`

## Storage Implication

Для базы это означает, что нам нужно хранить как минимум 3 слоя:

- raw response layer;
- normalized bond entities keyed by `isin`;
- time-based snapshots for price, yield, maturity and coupon schedule.

## Important Limitation

Эксперимент показал, что без сессионного токена мы видим только:

- контракт;
- модель;
- типы полей;
- ошибку доступа к данным.

Это нормально для текущего этапа: следующий рабочий шаг - добыть session bootstrap path и снять один реальный payload, чтобы сверить бандл и живой ответ.
