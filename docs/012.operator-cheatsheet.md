# 012 Operator Cheatsheet

## Purpose

Короткая рабочая шпаргалка для быстрого старта в проекте без чтения всего архива.

## What to Remember

- Главный источник данных: `https://next.privat24.ua/bonds/list`.
- Цель проекта: долгосрочные инвестиции в украинские ОВДП.
- Все решения и развилки обязательно документируем.
- Все markdown-артефакты именуем как `NNN.artefact_name.md`.
- Сырой слой, нормализованные данные и исторические снимки храним отдельно.
- Пытаемся извлечь все возможные данные и сохранять историю изменений.

## Current Technical State

- `API_INITIAL` работает через `POST`.
- Доступны `pubkey` и `xref`.
- `redirect` указывает, что нужен отдельный `sid`.
- `createSession` использует `POST /api/p24/init?dyn_string=...`.
- Рабочая session bridge цепочка пока не найдена.
- Реальный `bonds` JSON payload пока не снят.

## How to Continue

1. Сначала проверить, не изменился ли сетевой flow источника.
2. Потом искать валидный `sid` и `dyn_string`.
3. После успеха снять живой `bonds` payload.
4. Затем зафиксировать нормализованную схему хранения.
