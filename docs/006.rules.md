# 006 Agent Rules

## Базовые правила

- Сначала понимать задачу, потом предлагать решение.
- Не делать молчаливых предположений там, где ставка высокая.
- Все решения и развилки фиксировать в документации.
- Если есть неопределённость, явно помечать её как гипотезу.
- Все markdown-артефакты именовать по маске `NNN.artefact_name.md`.
- Порядковый индекс всегда начинать с `001` и сохранять без пропусков в пределах текущей серии артефактов.
- Стремиться извлекать все доступные данные и сохранять их в базе для исследования истории.
- Сырой источник, нормализованные данные и исторические снимки хранить раздельно, чтобы не терять контекст изменений.

## Для этого проекта

- Считать `Privat24` основным источником данных, пока не появится явная причина расширить набор.
- Отделять данные, допущения и рекомендации друг от друга.
- Не смешивать описание рынка с собственными правилами инвестирования.
- Открытые вопросы не прятать, а держать отдельным списком.
